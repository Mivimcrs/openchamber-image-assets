# 生图资产管理扩展 — 项目说明

任务：把已核验的生图流程做成 OpenChamber 扩展（对话/面板触发 → 侧边栏管理），
v2 加入参考图生图、本机加密密钥、接口与模型设置；v2.1.1 起改为 Git 仓库托管，CI 打包发版；
**v2.2.0 起多接口**：云端图片 API 与本机 ComfyUI 工作流并存，手动指定默认接口与默认模型，不预置任何服务商默认。

## 目录结构

| 路径 | 职责 |
| --- | --- |
| `package.json` | 扩展清单（同时是仓库清单；`version` 决定更新） |
| `panel/` | 面板：`index.html`（手改）+ `main.js`（构建产物） |
| `service/` | 扩展服务（构建产物，内联 `@openchamber/sdk`） |
| `plugin/` | 注入 OpenCode 的插件；`shared/` 由 `源码/共享` 同步 |
| `工作流/` | 本地 ComfyUI 的 API 格式模板（t2i / i2i），随仓库发版，构建时校验 |
| `源码/共享/` | 纯逻辑：`校验.js`、`资产库.js`、`配置.js`、`密钥.js`（DPAPI）、`迁移.js`、`模型.js`、`生成.js`（云端内核）、`ComfyUI.js`（本地客户端）、`工作流.js`、`统一生成.js`（按 kind 路由） |
| `源码/service/`、`源码/panel/` | 服务与面板源码（esbuild 入口） |
| `测试/` | `node --test`：校验/资产库/服务 + 配置密钥（DPAPI）+ 迁移 + 生成内核 + ComfyUI 打桩 + 插件 dry-run（69 项） |
| `tools/check.mjs` | 仓库自检（清单/入口/语法 + 多接口回归守卫 + 公开仓库卫生检查） |
| `tools/verify-save.mjs` | 端到端验证：单起 service 存一次测试密钥，断言 200 + 密钥文件 |
| `文档/` | 项目说明（本文件） |
| `.github/workflows/release.yml` | tag 上自检 → 打 zip → 发 Release |
| `构建.mjs` | 构建脚本（esbuild 依赖用 `IMAGE_ASSETS_BUILD_ENV` 或 `.build-env` 指定，见 README） |

> 构建产物直接输出到仓库根（`service/main.js`、`panel/main.js`），仓库根就是可安装的扩展包。
> 构建不生成 `panel/index.html`，改样式直接改它。

## 构建与测试

```sh
node 构建.mjs
node --test 测试\
node tools/check.mjs
node tools/verify-save.mjs --root .
```

## 数据位置

- 资产库：默认 `<用户主目录>\openchamber-image-assets\`（图片 / 索引 / 配置 / 运行时\参考），环境变量 `IMAGE_ASSETS_ROOT` 可覆盖
- 配置：`配置\settings.json`（`version: 2`：`interfaces[]`、`defaultInterface`、默认画幅/张数）
- 密钥：`配置\密钥\<接口id>.dat`（每接口一份 DPAPI 密文，当前 Windows 用户）；环境变量兜底 `IMAGE_ASSETS_KEY_<接口ID大写>`
- 旧版文件（`credentials.dat`、v1 `settings.json`）迁移后备份到 `配置\归档\`
- 安装：设置 → 扩展 → 添加扩展 → URL 填仓库地址（或文件夹选仓库根），批准 `service`

## 接口模型

```jsonc
{
  "version": 2,
  "defaultInterface": "comfy",
  "interfaces": [
    {
      "id": "comfy",            // 严格校验：只允许字母数字与 -_，非法直接报错
      "name": "本地 ComfyUI",
      "kind": "local",          // cloud | local
      "baseUrl": "http://127.0.0.1:8188",
      "defaultModel": "",       // 手填，可为空
      "models": [],             // 手填为主；「拉取」只补充，不覆盖
      "enabled": true,
      "comfy": {
        "timeoutMs": 900000, "pollMs": 1500,
        "workflows": { "t2i": "", "i2i": "", "video": "" },  // 空 = 用扩展自带模板
        "negative": "", "steps": 25, "cfg": 2.5,
        "sampler": "", "scheduler": "", "clip": "", "vae": "", "lora": ""
      }
    }
  ]
}
```

云端接口只存地址/模型/密钥，不写 `comfy` 段；本地接口不需要密钥（填了也不下发）。

## 设计决策

- 2026-11-14：生成内核共享、双入口（对话 + 面板创作）；密钥不可见（只显示末 4 位，不提供明文导出）
- 2026-11-18：仓库根 = 扩展包，源码在 `源码/`，构建输出到根；托管 GitHub，Actions 打包发版（v2.1.1）
- 2026-11-21：多接口改造（v2.2.0）
  - 删除内置服务商端点与默认模型，新装接口列表为空，默认接口必须手动指定
  - 接口按 `kind` 分云端/本地；本地走 ComfyUI API 提示词，模板来自实际跑通的 `/history` 提示词展开
  - 模型清单以手填为主，拉取（`/v1/models`、`object_info`）只做补充
  - 旧配置迁移成 `legacy` 一条云端接口并保留原密钥，但不设为默认
  - 视频只留槽位：本机无视频模型，无模板时明确报错并给配置指引
  - v2.2.1：资产库默认目录改为由用户主目录派生（`IMAGE_ASSETS_ROOT` 仍优先），仓库不含任何机器路径
